# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-08-27

### Added

- Initial release of `@novra/logger`.
- High-performance cascade log file rotation with size limits and retention controls.
- Recursive sensitive data masking and token sanitization.
- Pure JS diagnostic ZIP log packaging with `fflate`.
- Multi-user / multi-tenant log directory isolation.
- Zero-host-dependency Electron and Tauri adapters.
- Multi-language documentation (English, 简体中文, 日本語, 한국어, Español).
